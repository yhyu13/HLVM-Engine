# 50_ReSTIR_GI_Temporal — Finish Plan (2026-07-20)

## Context

The phase-1 work in this directory (2026-05-29 → 2026-06-15) **DID succeed** at
correcting the ReSTIR shaders (Generate/Temporal/Spatial + BilateralDenoise +
ReBLUR). The legacy critic at `claude.md` (REBUILD FROM ASH verdict, 2026-06-05)
described the **earlier** version of those shaders. Inspecting the current
sources on disk (`mtime 2026-06-15 14:08`):

- `ReSTIR_Generate_cs.hlsl` — actually does streaming RIS (M tent-distributed
  candidates per pixel, p_hat = luminance of radiance, deterministic hash, no
  FrameIndex in offset). Bug #1 (pass-through) is gone.
- `ReSTIR_Temporal_cs.hlsl` — does pure reservoir merge (combinedWSum/M,
  probabilistic selection, depth+normal validation, M clamp). Bug (TAA lerp)
  is gone.
- `ReSTIR_Spatial_cs.hlsl` — reads reservoir.y as the selected pixel, reads
  radiance at THAT pixel, and combines neighbors with pairwise MIS. Bug #2
  (output center radiance) is gone.

What was lost is **the test harness**. Commit `2216e71 (2026-07-16)` renamed
`TestFewBounceGI.cpp` -> `TestCornellBoxGI.cpp` and replaced the Sponza + ReSTIR
pipeline with a Cornell-box path tracer that only uses FGIPass. The ReSTIR
shader blobs were re-compiled into `TestCornellBoxGI_Data/` for archive, but
nothing exercises them.

The `51_PathTraceGI_Debug` session (2026-07-19) completed the same class of
bug fix on the Cornell-box pipeline (compact 64-byte fully-used payload;
camera; CPU reference; area-light coplanar). The lessons from that session
are applied directly here:

1. **GIPayload must be 64 bytes, fully used on both sides of TraceRay.**
   We wire the modern `Engine/Source/Runtime/Private/Renderer/Shader/GI/
   GIPathTracing.hlsl` (which is 64-byte and proven) through FGIPass — we
   do NOT use the legacy `TestCornellBoxGI_Data/FewBounceGI.hlsl` (128-byte
   with debug-only fields, would re-trigger the slangc dead-strip bug).
2. **No NEE-light coplanar with ceiling** in the Cornell box fixture —
   but Sponza has its own light setup through `FSceneResourceManager`
   / `FLightBuilder`. We build a single directional light and verify it
   is not coplanar with any large occluder.
3. **Camera rig:** outside the box, in front of the visible scene, FOV 90,
   -Z unprojection.
4. **CPU reference** isn't strictly required (we have TestPathTraceGI as a
   working sibling) but the validator must check structurally (not just
   mean luma).

## Architecture

```
glTF Sponza (Samples/Assets/sponza/Sponza01.gltf)
   ↓
BLAS / TLAS / RT buffers (FInstanceInfo.AlbedoColor; ktx->bindless for textures)
   ↓
GBuffer pass (GBufferSponzaVS/PS) → WorldPos/Normal/Material/Depth
   ↓
GI Ray Trace (FGIPass -> GIPathTracing.hlsl, 64-byte payload)
   ↓ OutputTexture (HDR rgb + hitDist alpha)
Bilateral Denoise (FBilateralDenoisePass)
   ↓ DenoisedHDR
ReSTIR Generate (FReSTIRPass::DispatchGeneration)
   ↓ Reservoir0/1 (selected pixel + W + p_hat)
ReSTIR Temporal (FReSTIRPass::DispatchTemporal, reproject + merge)
   ↓ TemporalReservoir0/1 + TemporalRadiance
ReSTIR Spatial (FReSTIRPass::DispatchSpatial, 3x3 + MIS)
   ↓ SpatialRadiance
ReBLUR temporal accumulator (FReBLURPass::Dispatch)
   ↓ FinalRadiance
Accumulate (FAccumulationPass if present) → tonemap → blit to swapchain
```

## Steps

1. **Wire ShaderMakeBuild.py**: add `create_restir_gi_temporal_shadermake()`
   factory. Source files: GIPathTracing, ReSTIR_Generate/Temporal/Spatial,
   ReBLUR, BilateralDenoise, GBufferSponzaVS/PS.

2. **Copy/adapt shader sources into `TestReSTIR_GI_Temporal_Data/`.** For
   GIPathTracing we re-include the proven source via CMake path config so
   we don't maintain a copy. For legacy Compute passes (ReSTIR/ReBLUR/Bilateral/
   GBufferSponza) we copy from `TestCornellBoxGI_Data/` into the new data
   dir because those blobs must be self-contained per test.

3. **Write `TestReSTIR_GI_Temporal.cpp`.** Modeled on `TestPathTraceGI.cpp`
   (clean FGIPass pattern) plus a Sponza scene loading block. Re-uses
   `FBilateralDenoisePass`, `FReSTIRPass`, `FReBLURPass`. Drops
   `FAccumulationPass` for v1 (single-frame result is OK for verification).

4. **Build target.** Wire cmake auto-discovery (`./Build.sh
   --Config=Debug --Target=TestReSTIR_GI_Temporal`).

5. **Run with debug dumps.** Add `HLVM_DUMP_RGI=1` env var following the
   `TestPathTraceGI` pattern so we can inspect intermediate buffers if
   the output is wrong.

6. **Visual validation + Python validator.** Validator checks black%
   < 5%, color variance over the Sponza region, frame-to-frame stability.

7. **Iterate** until the validator passes and the dump looks recognizably
   like Sponza with GI color-bleed.

8. **Commit** in logical chunks:
   - `feat: TestReSTIR_GI_Temporal shader data + ShaderMake wiring`
   - `feat: TestReSTIR_GI_Temporal.cpp — Sponza + FGIPass +
     Bilateral + ReSTIR + ReBLUR pipeline`
   - `feat: Sponza+ReSTIR validator + visual sanity dump`

9. **Set up `kanban-cron-overseer` style cron.** The single profile is
   `default`. We adapt the skill template into a cron that:
   - Re-runs TestReSTIR_GI_Temporal + validator every 15 min
   - Detects regression (validator pass→fail)
   - Posts a one-line status to the chat
   - Self-pauses after 3 consecutive failures with a state file
